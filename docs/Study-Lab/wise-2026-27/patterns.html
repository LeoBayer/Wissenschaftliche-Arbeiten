Question Patterns

Reusable blocks for active recall, recognition, and self-explanation

Design Rules

The study site should prefer active recall before passive reading. A good page therefore alternates between compact explanation and immediate retrieval.

Use these patterns consistently:

  • Recall first: Ask for the idea before revealing the answer.
  • Single choice: Use when exactly one distinction matters.
  • Multiple choice: Use when students must recognize a set of valid statements.
  • Keyword answer: Use when an exam answer must contain mandatory terms.
  • Numeric check: Use for formulas, indices, and project-management calculations.
  • Sequence check: Use for processes, stages, workflows, and procedures.
  • Self-reveal: Use for explanations, solution paths, and model answers.
  • Worked example: Use when the learner is new to a procedure and should see expert structure before solving alone.
  • Transfer prompt: Use when the exam likely asks for application to a case.

Research Anchors

This site uses a small practical subset of learning-science patterns:

  • Active learning should replace passive reading/listening with tasks that require cognitive engagement; Carnegie Mellon’s Eberly Center explicitly recommends short activities, application prompts, and visual interpretation rather than simply explaining everything for the learner: https://www.cmu.edu/teaching/resources/instructionalstrategies/activelearningstrategies/index.html
  • The Learning Scientists summarize six broadly useful strategies: spaced practice, retrieval practice, elaboration, interleaving, concrete examples, and dual coding. They also note that retrieval practice and spacing have especially strong support: https://www.learningscientists.org/blog/2016/8/18-1
  • Dual coding is most useful when the learner actively connects words and visuals, not when diagrams are decorative: https://www.learningscientists.org/blog/2017/4/20-1
  • Worked examples reduce unnecessary cognitive load for novices by showing the structure of expert problem solving before independent practice: https://education.nsw.gov.au/content/dam/main-education/about-us/educational-data/cese/2017-cognitive-load-theory-practice-guide.pdf
  • H5P’s content-type catalog is useful inspiration for interaction formats: quizzes, interactive books, interactive videos, image hotspots, drag/drop, fill-in-the-blanks, and branching scenarios: https://h5p.org/content-types-and-applications

Pattern Selection Matrix

Content shape Best pattern Why
Definition or distinction Single choice, keyword answer Checks whether the core boundary is clear
List of valid properties Multiple choice Forces recognition of all correct elements and distractors
Formula or calculation Numeric check + interpretation prompt Separates arithmetic from conceptual meaning
Process or lifecycle Sequence check + diagram Tests order and mechanism
Framework diagram Figure tile + explain-before-reveal Turns visuals into retrieval cues
Case application Transfer prompt + rubric Practices exam-style reasoning
New procedure Worked example, then near-transfer task Reduces cognitive load first, then increases independence
Similar concepts Comparison table + interleaved checks Builds discrimination, not isolated familiarity
Ethics or trade-off Pro/con grid + justified conclusion Forces balanced evaluation
Full exam prep Timed drill + scorecard + error log Converts practice into targeted next steps

Single Choice

Which statement best describes a critical path?

Use this when one distinction matters and the distractors can be meaningful. Weak distractors waste the interaction.

Multiple Choice

Which items are useful when evaluating a digital work arrangement?

Use this when a correct answer is a set. This is good for risks, mitigation measures, process activities, and valid interpretation statements.

Keyword Answer

Write the universal DWPM answer skeleton.

Use this when exact wording is less important than mandatory ingredients. Keep the keyword list short. Otherwise the check becomes a trap rather than feedback.

Numeric Check

Calculate CPI for EV = 1100 and AC = 900. Round to two decimals.

Use this for formula-heavy tasks, but always add a follow-up sentence: the number alone is not exam-ready.

Sequence Check

Write Simon's decision-making stages in order, separated by commas or arrows.

Use this for process logic. Good targets: Simon, PDCA, Scrum flow, risk management, CPM forward/backward pass, and project management process groups.

Self-Revealing Explanation

Reveal the reasoning path

Start from the decision criterion, name the mechanism, then apply it to the case. For digital work, do not merely say “remote work is flexible”; explain how task interdependence, media richness, and coordination overhead shape whether remote, hybrid, or co-located work is appropriate.

Use reveal blocks for answer keys and worked solutions. The learner should attempt first, reveal second.

Worked Example With Fading

Reveal worked EVM example

Given EV = 29,000, PV = 32,000, and AC = 28,000:

  1. Cost variance: CV = EV - AC = 1,000, so the project is under budget.
  2. Schedule variance: SV = EV - PV = -3,000, so the project is behind schedule.
  3. Cost performance index: CPI = EV / AC = 1.04, so cost efficiency is slightly above plan.
  4. Schedule performance index: SPI = EV / PV = 0.91, so schedule efficiency is below plan.
  5. Exam interpretation: behind schedule but within budget.

Next task should remove one step, then two steps, then the whole worked solution. This is the fading pattern: support first, independence later.

Transfer Prompt

Transfer task

A team introduces asynchronous status updates but still misses dependencies. Explain one likely cause and one design improvement.

Show model structure
  1. Define the coordination problem.
  2. Identify why asynchronous updates do not expose dependencies early enough.
  3. Recommend an intervention, for example dependency boards, shorter planning cycles, or explicit owner mapping.

Use this for application and evaluation. The answer should connect a concept to a concrete case fact.

Diagram Interpretation Pattern

![Short descriptive alt text](../resources/path/to/figure.png)

::: {.reveal-note}
<details>
<summary>Explain this diagram in 4 points</summary>

1. Name the framework.
2. Define the axes or components.
3. Explain the mechanism.
4. Apply it to one exam case.

</details>
:::

Use this whenever a slide contains a central framework. A diagram without an explanation task is mostly decoration.

Comparison And Contrast Pattern

| Criterion | Concept A | Concept B | Exam trap |
|---|---|---|---|
| Decision role | Supports decision | Executes/control decisions | Do not treat support and control as identical |

Use this for near-neighbor concepts: people analytics vs algorithmic management, automation vs augmentation, project vs program vs portfolio, plan-based vs agile.

Error Log Pattern

| Date | Task | Mistake | Missing concept | Next drill |
|---|---|---|---|---|
| 2026-10-12 | EVM | Mixed up PV and AC | Cost vs schedule interpretation | 5 EVM status checks |

Use this after every timed drill. The goal is not to prove that a topic was read. The goal is to find the next weak move.
