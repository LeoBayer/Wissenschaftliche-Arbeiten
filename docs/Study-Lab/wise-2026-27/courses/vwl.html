VWL für Wirtschaftsinformatiker

Economic intuition, models, and application

Role In The Semester Site

VWL pages should make model assumptions explicit. A useful page explains what the model assumes, what it predicts, and where the prediction can fail.

Because VWL is model-heavy, the default page shape should include a graph first, then the verbal explanation. If the mechanism can be simulated, add a tiny executable model or algorithmic trace.

Code Pattern: Tiny Simulation

Code 
import pandas as pd

def equilibrium(a, b, c, d):
    """Demand: Qd = a - bP, supply: Qs = c + dP."""
    price = (a - c) / (b + d)
    quantity = c + d * price
    return round(price, 2), round(quantity, 2)

base = equilibrium(a=100, b=2, c=10, d=1)
after_income_rise = equilibrium(a=125, b=2, c=10, d=1)

pd.DataFrame(
    [
        {"scenario": "base", "price": base[0], "quantity": base[1]},
        {"scenario": "income rise", "price": after_income_rise[0], "quantity": after_income_rise[1]},
    ]
)
What belongs into a strong economics model explanation?

Reveal example answer structure

For a supply-demand question, first identify the market, then decide whether demand or supply shifts, explain the mechanism, and only then state the effect on equilibrium price and quantity.
