DWPM Practice Test

Prototype 120-point exam rehearsal

Instructions

Use English. Treat one point as roughly one minute. Do not write keyword lists where the task asks for explanation or discussion.

Tip

After each task, mark missing answer fragments and convert them into flashcards.

Part 1: Project Management, 60 Points

Task 1: Scope Management, 12 Points

  1. Name the three elements of the Magic Triangle. (3)
  2. Explain why they are interdependent. (3)
  3. Give one meaningful project example for a scope change. (3)
  4. Apply the SMART criteria to one project goal. (3)

Task 2: Schedule Management, 16 Points

  1. Name one schedule management process and describe its main activities. (4)
  2. Explain the logic of earliest start, earliest finish, latest start, and latest finish. (4)
  3. Explain how slack is calculated. (3)
  4. Define the critical path and explain why it matters for project control. (5)

Task 3: Cost Management, 12 Points

A project has PV = 120, EV = 100, and AC = 80.

  1. Calculate CV, SV, CPI, and SPI. (6)
  2. Interpret whether the project is under or over budget. (3)
  3. Interpret whether the project is ahead or behind schedule. (3)

Task 4: Risk Management, 12 Points

A team can buy a tool or rent it. Buying is cheaper if demand is high but risky if demand is low.

  1. Explain how an EMV decision tree works. (4)
  2. Name the values needed to compare the two alternatives. (3)
  3. Explain how the recommendation should be justified. (3)
  4. Name one limitation of EMV. (2)

Task 5: Knowledge And Multi-Project Management, 8 Points

  1. Explain knowledge integration and knowledge sharing. (4)
  2. Name two challenges of knowledge management. (2)
  3. Define a program in multi-project management. (2)

Part 2: Digital Work, 60 Points

Task 6: People Analytics, 20 Points

  1. Define people analytics. (4)
  2. Describe two managerial uses. (4)
  3. Explain two risks for employees. (4)
  4. Explain inverse transparency. (4)
  5. Recommend two safeguards. (4)

Task 7: Digital Communication And Collaboration, 20 Points

  1. Describe the time-space matrix and give one example for each quadrant. (8)
  2. Explain two groupware issues in computer-mediated communication. (4)
  3. Apply the cooperative work framework to an instant messenger used by a project team. (4)
  4. Recommend two strategies for better awareness in hybrid teams. (4)

Task 8: AI At The Workplace And Agility, 20 Points

  1. Distinguish automation, augmentation, and delegation. (6)
  2. Explain why Copilot is usually augmentation rather than full automation. (4)
  3. Compare agile and plan-based methods using three criteria. (6)
  4. Explain why doing agile practices without being agile can fail. (4)

Self-Assessment Rubric

Level Signal
Weak Keywords without definitions or case application.
Solid Correct definitions plus explanation of mechanisms.
Exam-ready Compact concept, concrete case evidence, risk or limitation, justified conclusion.

Quick Checks

Reveal: Task 3 interpretation CV = 20, SV = -20, CPI = 1.25, and SPI = 0.83. The project is under budget but behind schedule, so the answer must not say the project is simply “good”.
